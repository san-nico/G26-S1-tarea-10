# Taller Frontend 2026

Landing page de prueba del **Taller Frontend 2026**, desarrollado con **Next.js**.  
Presenta información del curso en, tecnologías utilizadas, pilares del taller y equipo de relatores.

## Demo

🌐 g26-s1-tarea-10.vercel.app

## Tecnologías

- Next.js
- React

## Scripts

| Comando          | Descripción                     |
| ---------------- | ------------------------------- |
| `npm run dev`    | Inicia el entorno de desarrollo |
| `npm run build`  | Genera la versión de producción |
| `npm run start`  | Ejecuta la versión construida   |
| `npm run lint`   | Revisa el código con ESLint     |
| `npm run deploy` | Publica en GitHub Pages         |

## Contenido

La información editable del sitio se encuentra en:

```txt
src/data/contenido.json
```

Las imágenes utilizadas están en:

```txt
public/img/
```
